# Сервис рассылки уведомлений

Рассылка Email / SMS / Push с учётом разрешений пользователя.

## Что реализовано
- Абстрактный `Notification` и его наследники (`ClassroomChangeNotification`, `DeadlineReminderNotification`).
- Класс `User` с проверкой разрешенных каналов.
- Каналы доставки (`EmailChannel`, `SmsChannel`, `PushChannel`) с обработкой проверяемого исключения `NotificationDeliveryException`.
- Сервис `NotificationService.broadcast`, который формирует текст один раз и обрабатывает ошибки доставки.


## Окружение и сборка

* **Версия JDK:** OpenJDK 25.0.5.1

## Команды компиляции и запуска

в директиории /src
```bash
javac -encoding UTF-8 *.java
java Main
```
